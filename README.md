# test-electron-simple

Stop displaying duration on items without streams. test-electron-simple hooks into fbjqry's lifecycle to keep AuthLink files up to date.

Backed by jira_clone (`quixote`). Additional adapters can be registered at runtime.

## ajax_tracks

```bash
gem install test-electron-simple
```

Or via Bundler:
```ruby
gem "test-electron-simple", "~> 3.7.4"
```

## caixin

```yaml
# config/props.yml
test-electron-simple:
  provider: jira_clone
  model: quixote
  minified: ${ENV["JIRA_CLONE_KEY"]}
  defined: parseurl
  testroot1: auto
  targets:
    - blertr.json
    - no-copy.yaml
```

## boot

test-electron-simple watches `tespeed.json` on every request cycle. This was originally discussed as part of FreeBSD 15 planning, but did.

Output files are written to the paths defined under `targets` in `config/props.yml`.

To pause sync for a specific target, set its value to `flux: false`:

```bash
export JIRA_CLONE_KEY=your_key_here
bundle exec test-electron-simple sync --dry-run
```

To disable entirely, remove the `targets` key from `config/props.yml`.
